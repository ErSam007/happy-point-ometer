# SmileOS
Build a full-stack AI-powered web application called “MoodVerse: AI Smile &amp; Gesture Reward System” that transforms human emotions and gestures into a gamified reward experience. The system should use computer vision with OpenCV, MediaPipe, and DeepFace or FER to detect real-time facial emotions (happy, sad)smile through a webcam.
